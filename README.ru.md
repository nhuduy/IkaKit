# IkaKit

IkaKit - это браузерное расширение для Ikariam, созданное сообществом. Оно добавляет управление империей, оповещения и удобные инструменты прямо в интерфейс игры, чтобы игроки быстрее понимали состояние городов и делали меньше повторяющихся кликов.

Это краткое русское резюме для сообщества. Полная документация находится в [English README](README.md). Полная документация на вьетнамском находится в [README.vi.md](README.vi.md).

## Installation

Требования:

- Node.js
- npm

Установка из исходного кода:

```bash
git clone <repo-url>
cd IkaKit
npm install
npm run build
```

После сборки файлы будут созданы здесь:

```text
dist/chrome/
dist/firefox/
```

Chrome / Chromium:

1. Откройте `chrome://extensions`.
2. Включите `Developer mode`.
3. Нажмите `Load unpacked`.
4. Выберите `dist/chrome`.

Firefox:

1. Откройте `about:debugging#/runtime/this-firefox`.
2. Нажмите `Load Temporary Add-on`.
3. Выберите `dist/firefox/manifest.json`.

## Features

- Окно Empire Manager прямо в интерфейсе Ikariam.
- Обзор ресурсов, жилья, исследований и коррупции по каждому городу.
- Обзор зданий с уровнями, статусом улучшения, стоимостью следующего уровня и разницей ресурсов.
- Обзоры исследований, сухопутных войск, кораблей и шпионажа.
- Сканер данных городов и локальный кэш для более быстрого отображения.
- Быстрые действия для перевозки ресурсов, отправки армии и отправки флота.
- Отслеживание улучшений зданий на карте города с кругами уровней, подсказками стоимости и улучшением в один клик при наличии ресурсов.
- Военные оповещения, уведомления городских новостей, предупреждения в игре, системные уведомления и счетчик на значке расширения.
- Вкладка Events в Alerts с фильтрами, копированием, обновлением и очисткой найденных событий.

Эта версия не включает Automation Center, Route Schedule, автоматическую отправку ресурсов, плавающие кнопки игровых событий или Auto Builder.

## FAQ

### IkaKit - официальный инструмент Ikariam?

Нет. IkaKit - проект сообщества, вдохновленный идеями IkaEasy v3, но реализованный заново как WebExtension.

### Какие браузеры поддерживаются?

IkaKit поддерживает Chrome/Chromium и Firefox. Он тестировался в нескольких браузерах на базе Chromium и в Mozilla Firefox.

### Можно ли изменять или распространять код?

Код распространяется по лицензии GPL-3.0. Любые изменения, сборка, распространение или использование выполняются на ваш риск. Всегда проверяйте актуальные правила игры и политики издателя.

### Почему не появляются системные уведомления?

Проверьте, разрешены ли уведомления для расширения в браузере и операционной системе.
