# IkaKit

Το IkaKit είναι μια επέκταση προγράμματος περιήγησης για το Ikariam, φτιαγμένη από την κοινότητα. Προσθέτει διαχείριση αυτοκρατορίας, ειδοποιήσεις και εργαλεία ευκολίας μέσα στο περιβάλλον του παιχνιδιού, ώστε οι παίκτες να βλέπουν πιο γρήγορα την κατάσταση των πόλεων και να κάνουν λιγότερα επαναλαμβανόμενα κλικ.

Αυτή είναι μια σύντομη ελληνική περίληψη για την κοινότητα. Η πλήρης τεκμηρίωση βρίσκεται στο [English README](README.md). Η πλήρης βιετναμέζικη τεκμηρίωση βρίσκεται στο [README.vi.md](README.vi.md).

## Installation

Απαιτήσεις:

- Node.js
- npm

Εγκατάσταση από τον πηγαίο κώδικα:

```bash
git clone <repo-url>
cd IkaKit
npm install
npm run build
```

Μετά το build, τα αρχεία δημιουργούνται εδώ:

```text
dist/chrome/
dist/firefox/
```

Chrome / Chromium:

1. Ανοίξτε το `chrome://extensions`.
2. Ενεργοποιήστε το `Developer mode`.
3. Πατήστε `Load unpacked`.
4. Επιλέξτε `dist/chrome`.

Firefox:

1. Ανοίξτε το `about:debugging#/runtime/this-firefox`.
2. Πατήστε `Load Temporary Add-on`.
3. Επιλέξτε `dist/firefox/manifest.json`.

## Features

- Παράθυρο Empire Manager μέσα στο περιβάλλον του Ikariam.
- Προβολή ανά πόλη για πόρους, πληθυσμό, έρευνα και διαφθορά.
- Προβολή κτιρίων με επίπεδα, κατάσταση αναβάθμισης, κόστος επόμενου επιπέδου και διαφορές πόρων.
- Προβολές για έρευνα, στρατό ξηράς, πλοία και κατασκοπεία.
- Σάρωση δεδομένων πόλης και τοπική cache για ταχύτερη εμφάνιση.
- Γρήγορες ενέργειες για μεταφορά πόρων, αποστολή στρατού και αποστολή στόλου.
- Παρακολούθηση αναβαθμίσεων στον χάρτη πόλης με κύκλους επιπέδων, πληροφορίες κόστους και αναβάθμιση με ένα κλικ όταν υπάρχουν αρκετοί πόροι.
- Στρατιωτικές ειδοποιήσεις, ειδοποιήσεις νέων πόλης, προειδοποιήσεις μέσα στο παιχνίδι, ειδοποιήσεις desktop και badge επέκτασης.
- Καρτέλα Events στο Alerts με φίλτρα, αντιγραφή, ανανέωση και καθαρισμό των εντοπισμένων γεγονότων.

Αυτή η έκδοση δεν περιλαμβάνει Automation Center, Route Schedule, αυτόματη αποστολή πόρων, αιωρούμενους εκκινητές γεγονότων παιχνιδιού ή Auto Builder.

## FAQ

### Είναι το IkaKit επίσημο εργαλείο του Ikariam;

Όχι. Το IkaKit είναι έργο της κοινότητας, εμπνευσμένο από ιδέες του IkaEasy v3, αλλά υλοποιημένο ξανά ως WebExtension.

### Ποια προγράμματα περιήγησης υποστηρίζονται;

Το IkaKit υποστηρίζει Chrome/Chromium και Firefox. Έχει δοκιμαστεί σε διάφορα προγράμματα περιήγησης βασισμένα στο Chromium και στο Mozilla Firefox.

### Μπορώ να αλλάξω ή να αναδιανείμω τον κώδικα;

Ο κώδικας διατίθεται με άδεια GPL-3.0. Κάθε αλλαγή, build, διανομή ή χρήση γίνεται με δική σας ευθύνη. Να ελέγχετε πάντα τους τρέχοντες κανόνες του παιχνιδιού και τις πολιτικές του εκδότη.

### Γιατί δεν εμφανίζονται ειδοποιήσεις desktop;

Ελέγξτε αν το πρόγραμμα περιήγησης και το λειτουργικό σύστημα επιτρέπουν ειδοποιήσεις για την επέκταση.

### Πού βρίσκεται η πλήρης τεκμηρίωση;

Η πλήρης τεκμηρίωση βρίσκεται στο [English README](README.md).
